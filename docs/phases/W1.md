# Phase W1: Writer, to the behaviour of 15

The plan of phase W1 of the [roadmap](../roadmap.md), written when it
started on 2026-11-18. It follows "How a phase runs": the rows of the
phase, the parity rows that test each one, what is missing, how each is
checked, and the order of the pull requests. It is corrected as the phase
goes and closed with it.

The phase owned 28 rows when it started; four moved to later phases on
2026-11-18 (below), so it owns 24 rows of [`corpus/inventory/writer.tsv`](../../corpus/inventory/writer.tsv)
and 8 items of the [backlog](../backlog/deferred.tsv) (B-012, B-020 to
B-025, B-038). Desk follows GNOME where it and iWork differ (D-022), and
keeps what Pages '09 did inside a shared feature (D-003).

## ODF

Where ODF has a place, Desk uses it: `style:drop-cap` for the drop cap,
`text:section` with `style:columns` for columns on the selection, the
`fo:language` and `fo:country` of the default style for the language of
the document, `table:table-template` in `office:styles` for the table
styles (W080, W127). The chart styles have no place in ODF; like the
styles of drop caps, they are settings of the document, the `ChartStyles`
item of `settings.xml`. The rows that will need a `desk:` extension, each defined
in [odf-extensions.md](../odf-extensions.md) in the pull request that
adds it: the gradient and image fill of text (W052). The title of a
table (W138) is an option kept in `desk:table`, and its lock (W140) the
standard `style:protect` of its frame. A table made from dragged cells (W130) is an ordinary table; the custom
formats of cells (W132) are settings of the document, the `CustomFormats`
item of `settings.xml`, and each cell keeps its own in `desk:table`. Screen View (W043) is a way of showing the document, not part of it, and writes nothing to the file; only the preference for new documents is kept, in the preferences of Desk. A thread of one text box (W091) is kept as
`desk:thread`; the number and the color of a thread are worked out from
its place among the threads, and longer threads are the standard
`draw:chain-next-name` links. Automatic fractions (W061) needed none: the
setting belongs to the computer, as in Pages. The layout of 15.4 (step 17)
changed nothing in the file: the outline that text wraps tightly around
is still the standard `draw:contour-polygon`, now traced as Pages 15.4
traces it.
