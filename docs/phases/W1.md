# Phase W1: Writer, to the behaviour of 15

The plan of phase W1 of the [roadmap](../roadmap.md), written when it
started on 2026-11-18. It follows "How a phase runs": the rows of the
phase, the parity rows that test each one, what is missing, how each is
checked, and the order of the pull requests. It is corrected as the phase
goes and closed with it.

The phase owned 28 rows when it started; four moved to later phases on
2026-11-18 (below), so it owns 24 rows of [`corpus/inventory/writer.tsv`](../../corpus/inventory/writer.tsv)
and 8 items of the [backlog](../backlog/deferred.tsv) (B-012, B-020 to
B-025, B-038). Desk follows GNOME where it and iWork differ (D-022), and
keeps what Pages '09 did inside a shared feature (D-003).

## Order of the pull requests

Small pull requests, each reviewed on its own. The Mac is used in one
session at the start, announced to the owner first, and in one at the
end; the rest is checked against the PDFs of 15.4 already in the corpus.

1. This plan.
2. Session on the Mac: what Pages 15.4 does for each row marked "Before",
   and the check of the rows marked "Check". From it, the parity rows of
   the features of the 15, a new group of `corpus/matrix.tsv` whose phase
   column takes the ids of the roadmap. Done on 2026-11-18: 18 rows,
   `PXV-01` to `PXV-18`. W048 keeps the steps by kind of the '09, since
   Pages 15.4 only steps by page (D-003).
3. Capitalization: Start Case and the transformations (W054).
4. Automatic fractions (W061).
5. Quote style and converting quotes (W062); one replacement list for the
   three apps (W064).
6. Default font in Preferences (W051); default text box style per
   document (W081).
7. Language and region of the document (W072).
8. Drop cap (W060), in the standard `style:drop-cap` of ODF.
9. Gradient and image in text (W052).
10. Dragging list items by the bullet (W088).
11. Columns on the selection (W089).
12. Threads of linked text boxes (W091).
13. Table and chart styles, in view when inserting, with copy and paste
    of the style (W080, W127, B-012).
14. Table title and lock (W138, W140).
15. A table from cells, dragging cells, pushing objects aside, managing
    formats (W130, W132, B-012).
16. Screen View, also inside full screen (W043, W012, B-038), and the
    check that the table of contents of the sidebar is live (W041).
17. The layout of 15.4: line placement, justification and hyphenation,
    table of contents, oval, inline sound (B-020, B-022 to B-025).
18. The metrics of the Apple fonts, measured on the Mac (B-021).
19. End: the validation on the Mac, with what the session of step 2 left
    (W061, W062, W072, W081, W131, W132), the backlog of the phase,
    `ci/check-backlog.py --phase W1` and `ci/check-all.sh`.

## ODF

Where ODF has a place, Desk uses it: `style:drop-cap` for the drop cap,
`text:section` with `style:columns` for columns on the selection, the
`fo:language` and `fo:country` of the default style for the language of
the document. The rows that will need a `desk:` extension, each defined
in [odf-extensions.md](../odf-extensions.md) in the pull request that
adds it: the gradient and image fill of text (W052), the title and the
lock of a table (W138, W140), the number and color of a thread of linked
boxes (W091). Automatic fractions (W061) needed none: the setting
belongs to the computer, as in Pages.
