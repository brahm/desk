# id | name | source label in iWork | what it does and what it holds | where it was in iWork '09 | reference in the current iWork | state in Desk today | shortcut
# State, against the Desk of today (interface B in Writer, and the windows of phase 2 in Tables and Slides):
# exists = Desk already shows it this way, even if it does nothing yet; changes = Desk has it in another form or another place; new = to be written.
# "-" = does not apply.
