About

I used Linux in college. But life kept sending me Microsoft Office files and asking for things in Photoshop, so around 2008 I gave in and moved to the Mac. That is where I met iWork, which came with the computer. It was love at first sight: before long I had dropped Microsoft Office for good.

Years went by, Apple rewrote iWork for 64 bits, and the new version shipped without many useful features that never came back. I missed iWork '09, and I still do.

Now Linux is my main system again, and I decided to build for it the iWork equivalent I wished I had. LibreOffice is an admirable project, but it was never for me: it has a lot I don't use, and it doesn't look at home in GNOME, my favorite desktop. Desk is my attempt to bring both together: the simplicity of iWork '09 and the look and feel of a real GNOME app.

Some things you can expect:

  • The three apps share one document model, so a table, a chart or a block of text behaves the same in all of them.
  • Built with Rust, GTK 4 and Libadwaita, following the GNOME Human Interface Guidelines.
  • Documents are saved as OpenDocument (ODF), and your old iWork '09 and '08 files will open too.
  • The document engine is separate from the interface, in libraries that other projects can use. There is already a command-line converter that runs with no graphical interface at all.
  • And if the community asks really nicely, we will port it to Plasma. :)

Desk is being built by me together with Claude, Anthropic's AI. That is no excuse for shortcuts: every feature of Pages, Numbers and Keynote '09 became a row in a parity matrix (585 of them), every change goes through review and a CI that checks formatting, lints, tests and licenses, and the output is compared, pixel by pixel, with PDFs made by the real iWork 9.3 in a virtual machine.

What comes next

We are starting with Desk Writer, because the text engine is the hardest part and the other two apps depend on it. The first test version is coming soon, and more will follow bit by bit as each stage is done.

  1. Foundation done

    Code layout, CI, licenses, icons, and a virtual machine with iWork 9.3 that makes the reference documents.

  2. Text core in progress

    Document model, text engine and pagination. It already reads and writes ODT and makes PDFs from the command line.

  3. iWork reader

    Opening your old .pages files, and measuring, feature by feature, how close we are to the original.

  4. Minimal editor and test version

    Opening, editing and saving formatted text in Desk Writer, shipped as a nightly Flatpak.

  5. Styles, lists and document structure

    Spelling, sections, columns, headers, footnotes and tables of contents. The first beta comes out here.

  6. Objects, tables, formulas and charts

    Images, shapes and effects, and the table and chart engine that Desk Slides and Desk Tables build on.

  7. Review, templates, printing and formats

    Change tracking, comments, templates, mail merge, and export to PDF, Word, RTF and ePub.

  8. Desk Writer 1.0, then Slides and Tables

    Parity with Pages '09 and version 1.0. Desk Slides and Desk Tables start as soon as the object and table engines are ready.

Install

There is nothing to install yet. When the first test version is out, Desk will ship as a Flatpak from its own repository, and all it will take is adding the repository and installing the app:

flatpak remote-add --if-not-exists desk https://brahm.github.io/desk/desk.flatpakrepo
flatpak install desk br.com.brahm.Desk.Writer

These commands will only work once the first version is out. Meanwhile, you can build it from the source code.

Get involved

Desk is free software and just getting started, so every bit of help counts. We are one person and one AI: please be patient with us, and thank you in advance.

  • Report an issueFound a bug? Tell us what happened and how to repeat it.
  • Request a featureMissing something from iWork '09? Just ask.
  • Send old iWork documentsPages, Numbers and Keynote '09 files help us test compatibility.
  • Contribute codeThe code is on GitHub, in Rust, with CI running every check before each merge.
  • TranslateTranslations open once the interface has text to translate, for every language GNOME supports.
